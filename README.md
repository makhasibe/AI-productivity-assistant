# Build the AI Workplace Productivity Assistant as one integrated, modern responsive SaaS dashboard

Build the AI Workplace Productivity Assistant as one integrated, modern responsive SaaS dashboard. Implement all five requested AI workflows: smart email generator with selectable tones and editable output; meeting-notes summarizer with summary/action items/decisions/deadlines; task planner with prioritized time-block schedules; research assistant with insights/takeaways/recommendations; and contextual workplace chatbot. Use Lovable Cloud and Lovable AI for working AI features, with polished sidebar navigation, clear labeled inputs, editable outputs, responsible-AI disclaimer and guidance, and professional prompt engineering. Test the flows and make the experience feel production-ready.

This project was built with [Lovable](https://lovable.dev).
